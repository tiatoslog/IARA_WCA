# arquivos/packs-arte/

Os `.zip` originais dos packs de arte avaliados. **Ficam fora do Git** — ver a
explicação de licença em `../README.md`.

| Arquivo | Licença | Situação |
|---|---|---|
| `free-office-pixel-art.zip` | free to use any way you want, sem restrição comercial | **em uso** — os PNG vão versionados em `public/escritorio/` |
| `Modern_Interiors_Free_v2.2.zip` | proíbe uso comercial | descartado |
| `ModernOffice2DProps_v1.0.zip` | proíbe deixar os arquivos originais baixáveis | descartado |

Créditos do pack em uso: `iara-os/apps/web/CREDITOS.txt`.

## Antes de propor um asset novo

Checar, nesta ordem:

1. A licença permite uso comercial? (o projeto é comercial)
2. A licença permite servir o arquivo por HTTP, onde ele fica baixável por URL
   direta?

Se qualquer uma das duas for não, o asset não entra — nem no repositório, nem em
`public/`.
