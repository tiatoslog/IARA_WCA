# arquivos/documentos/

Documentos de apoio em formato binário: especificações, contratos, planilhas.

Vão versionados — são leves e fazem parte do registro do projeto.

## O que NÃO vai aqui

- **Dado pessoal.** CPF, dados bancários, contato ou documento de pessoa física
  não entram no repositório em hipótese nenhuma. Se um documento desses precisar
  existir, ele vai para uma pasta própria, fora do Git.
- **Binário pesado.** Apresentação, vídeo, captura de tela.
- **A versão editável da documentação técnica** — essa é gerada, e mora em
  `docs/gerado/`.
